# LedgerMind — Agentic AI GST Copilot

Futuristic landing page and prototype for an AI copilot that turns invoice photos and WhatsApp bills into GST-ready books.

**Live site:** https://nikhil-creat.github.io/ledgermind/

## Features
- Multi-agent invoice pipeline demo
- AI chatbot (Groq, Llama 3.3) with voice input
- GST calculator and liability forecast
- Pricing, architecture and tech stack sections

## Run
Open `index.html` in a browser. For live chat, tap the key button and paste a free Groq API key from console.groq.com (stored only in your browser).

## Payments
Pricing buttons open a UPI sheet with a dynamic QR (amount pre-filled) and an "Open UPI app" deep link. `upi-qr.png` is the static fallback QR. Change the UPI ID in the `CFG` line inside `index.html`.

## Deploy
Settings → Pages → Deploy from a branch → main → / (root).
